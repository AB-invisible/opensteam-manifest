# Support and Escalation

When to use self-serve docs, when Atis can help, and when you need a human.

## Self-serve first

Try these before opening a ticket:

1. **Getting Started** — account setup flow
2. **Discord Verification** — verify blocks, VPN, blacklist
3. **API Troubleshooting** — 401/403/429 errors
4. **Plans and Limits** — quotas and upgrades
5. **Hosted Bots** — branded vs custom setup
6. Website **/docs** and **/pricing**

## What Atis can answer

- How verification works
- How to use `/gen`, `/request`, API endpoints
- Plan limits and where to upgrade
- Dashboard navigation (API keys, usage)
- General platform features (Forge, shop cosmetics, incidents page)

Atis answers **only from the knowledge base**. If it is not documented, Atis will say so.

## What needs a human (open a ticket)

| Category | Examples |
|----------|----------|
| **account** | Data export, deletion (with confirmation), login issues after verify |
| **ban_appeal** | Platform ban, suspension, jail you disagree with |
| **billing** | Pandabase payment issues, wrong plan after purchase, refunds |
| **technical** | Reproducible bugs, server-side errors |
| **api** | Key issues after all troubleshooting steps |

## How to open a ticket

1. Use the **support form** on the website or email channel documented in Discord
2. Use the **same email** as your OpenSteam account when possible
3. Include: Discord username, what you tried, error messages (redact API keys)

## AI support agent

Incoming tickets may receive an **automated AI reply** first for simple issues (API key inactive, rate limits, where is my key, onboarding).

- If resolved, ticket may auto-close
- If not resolved, reply ends with: *A member of our team will follow up shortly.*

## Data requests

- **Export data:** request via support; export JSON emailed to account email
- **Delete account:** explicit consent required; deletion is permanent

Atis cannot process GDPR requests without the official flow.

## Appeals and moderation

Discord moderation (warn, mute, kick, ban) is separate from platform API bans but may be linked for serious abuse.

- Do not argue punishment details with Atis
- Use the documented **appeal** or **ticket** process
- Provide respectful context and evidence

## Response expectations

- Automated replies: minutes
- Human staff: varies by queue — be patient
- Do not ping staff repeatedly for the same ticket

## Emergency / outages

Check **http://127.0.0.1:3000/incidents** for platform status before opening "is it down?" tickets.
