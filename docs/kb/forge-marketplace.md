# Forge Script Marketplace

**Forge** is OpenSteam's user script marketplace on the platform.

## What Forge is

- Users can upload and share extension scripts
- Scripts can be starred, commented on, and discovered by others
- Public scripts go through **moderation** before wide visibility

## Upload flow

1. Open **Forge** from the dashboard or site navigation
2. Upload your script following format requirements
3. Script may enter **PENDING** status for staff review
4. After approval, script becomes publicly available per policy

## Moderation

Forge uses automated checks plus staff review:

- Heuristic pattern detection
- LLM-assisted moderation pass for risky content
- Staff can approve or reject pending scripts

**Atis cannot** approve scripts or override moderation decisions.

## Public vs private

Not all scripts are immediately public. Check script status in your Forge profile. Rejected scripts need fixes and re-submission per staff feedback.

## Rules of thumb

- No malicious payloads or abuse tools
- Respect copyright and platform terms
- Do not use Forge to distribute stolen credentials or malware

## Issues

| Issue | Action |
|-------|--------|
| Script stuck pending | Wait for staff review; do not spam pings |
| Script rejected | Read rejection reason; fix and resubmit |
| Report abuse | Open support ticket with script ID |

## Relation to manifests

Forge scripts are separate from Steam manifest generation (`/gen`, API). They extend platform tooling — not a replacement for API keys or verification.
